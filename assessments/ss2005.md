## 6. Guts (axis: 85.0)

Code 1,048,576 B · functions 2,568 · MMIO refs: scif 2, rtc 3, g2ext 52 ·
BIOS vector refs: none · flags: `eeprom_bios`, `serial`, `rtc` → −15.
Carve base `0x8c020000`, entry `0x8c020fe0`, header title `SUPER SHANGHAI 2005`.
SDK strings: Kunoichi2 2.07 / Ninja2 / `syStartCwKn` / AIPKN, KAMUI2, CRI —
all Mar-2001-era Katana-adjacent builds; `guts.sdk_strings` also names the Sega/CRI
sound stack doing the ARAM bank load (`sd2 for DC Ver 2.50.17`, `mwSb`, `MANATEE.DRV`,
CRI ADX/Sofdec) — the same driver family whose banks the official Ikaruga DC port
trimmed 4× to fit 2 MiB (kb §4.d precedent).

## 7. Controls (axis: 100.0)

Cabinet: one 8-way stick and three game buttons (`controls.device_class = stick`). The
game's own INPUT TEST menu (in-binary, `guts.sdk_strings`) lists UP/DOWN/RIGHT/LEFT +
SELECT/CANCEL/HELP + START — 1:1 on a DC pad.
Sources: MAME src/mame/sega/naomi.cpp @59e7c0b INPUT_PORTS `naomi`;
[arcadeitalia ss2005](http://adb.arcadeitalia.net/dettaglio_mame.php?game_name=ss2005)
and [ss2005o](http://adb.arcadeitalia.net/dettaglio_mame.php?game_name=ss2005o)
(8-way joystick + 6-button JVS standard declaration, 2P solo). The
[LaunchBox](https://gamesdb.launchbox-app.com/games/details/39342-super-shanghai-2005)
claim of a "dual-analog control scheme" describes the PS2 pad layout — the binary's
own `ANALOG STICK` / `DIRECTIONAL BUTTON` strings are PS2-origin leftovers — and is
discounted for the cabinet.

## 9. Risks & notes

- **ARAM is the binding region on a conservative fallback**: this pre-v7 sidecar has no
  `content_total`, so the scorer keys on the fill-excluded content-high address
  (1.75×) — the 1,435,800 B of real above-cap content is what a port must trim, with
  the Ikaruga 4× audio-trim precedent (kb §4.d) as released-port proof. A v7+ re-capture
  would key ARAM (and VRAM) on volume and can only raise the score.
- **VRAM is milder than its 1.37× fallback implies**: only 2,763,089 B of nonzero
  content, nearly all parked above the 8 MB line — relocation work, not raw overflow.
- **PS2-CD origin bounds the difficulty**: the 2004 PS2 release means the content fits
  console-class budgets; the Naomi build simply loads whole banks.
- **Rendering must be verified on real DC hardware** (working-style rule): the fork's
  early captures of this title were display-blind (stale TA frame, kb §4.m); v4+
  captures render the demo, and the emulator-side diagnostic is the raw-VRAM decode
  recipe (`FLYCAST_VRAMDUMP` + `vramdump2png.py`, kb §4.m).
- Main watermark 32,505,920 B is byte-identical to `kurucham`'s and equals this title's
  write-truth address peak — part of the shared `0x1F00000` structure/stream-cache
  reading (kb §6 item 3); treat the address extent with suspicion, the content volume
  is the trustworthy figure.
- MAME emulation status for the set is preliminary / imperfect graphics + sound
  (arcadeitalia, mirroring MAME `GAME_FLAGS`) — consistent with a title that trips
  emulator display paths, as observed here.
